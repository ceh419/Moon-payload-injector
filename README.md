# Moon Location Tracker

**Moon Location Tracker** ایک powerful IP-based location tracking tool ہے جو کسی بھی IP کی جغرافیائی معلومات دیتا ہے۔

## ⚙️ Requirements
- Python 3
- requests library

Install with:
```bash
pip install requests
```

## ▶️ Usage
```bash
python3 moon_location_tracker.py
```
